## GitHub Pages로 열면 자동 이동 / Auto-redirect via GitHub Pages

`index.html`이 위 링크로 자동 이동시켜 줍니다 — 즉 Pages 주소
(`https://사용자명.github.io/저장소명/`)만 알려줘도 바로 전시실 1이 열립니다.

If GitHub Pages is enabled for this repo (Settings → Pages), the root
`index.html` auto-redirects to the link above — so sharing just the Pages
URL (`https://username.github.io/repo-name/`) opens Room 1 directly.
