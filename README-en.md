# Resonance of Silence

An interactive tactile & audio exhibition for blind and visually impaired visitors.

## 🔗 Open the exhibit

**https://claude.ai/artifact/CNFb2GFqxLDwYnzRSbcqoa**

Just this one link — starting from Room 1, in-app buttons take you to

## Auto-redirect via GitHub Pages

If GitHub Pages is enabled for this repo (Settings → Pages), the root
`index.html` auto-redirects to the link above — so sharing just the Pages
URL (`https://username.github.io/repo-name/`) opens Room 1 directly.
